## Known limitations / v1.3 punch list

- **Accent color picker is display-only** in v1.2. The chip row in
  Settings → General shows the palette but isn't a stateful picker.
  Full runtime token-resolver wiring is real surgery — `.tint()` at
  the root covers most controls; custom components (SegmentedToggle's
  selected color, status dots) still use the static `#2F6BFF`.
- **"Clear" terminal action removed** from the 3-dot menu (was in spec).
  Reaching from WorkspaceView into a child TerminalView's PTY to send
  ESC c is non-trivial via Notifications. "Reset shell" (full respawn)
  covers the common need.
- **Browser pane resize** triggers a screenshot scale change in cuabot
  — Diakonos's coord translation uses the latest `scale` value the
  poller has, so it self-corrects within ~100 ms. May feel briefly off
  during fast resizes.
- **Floating Chromium window** (3-dot → Open in floating window) opens
  a new chromium window inside the sandbox; Xpra streams it as a
  separate floating Mac window via cuabot's default. Visual handoff
  hasn't been tested with the user, but the mechanism is sound.
- **Pane positions are fixed** — no drag-to-reorder. Kinds are
  swappable via Close → empty → re-pick.
