## Headlines (both verified live this session)

### v1.3 MCP-in-pane bug — FIXED

**The bug:** v1.3 registered MCP servers in pane `onSpawn`, which fired
*after* the PTY had already exec'd claude/codex. The agent in the pane
read its config at startup, missed the MCP entry. The Mac-shell-level
`claude mcp list` test in the v1.3 "VERIFIED" claim was a different
claude session that ran after registration completed.

**The fix:** `MCPRegistration.bootstrap()` runs synchronously at
`DiakonosApp.init()` — before any pane spawns. Both Claude Code and Codex
configs are written before any agent starts.

**Real verification (this session):**
```
$ open /Applications/Diakonos.app                     # Diakonos launches
$ claude mcp list | grep diakonos
diakonos-browser: python3 /Applications/Diakonos.app/Contents/Resources/mcp_browser.py - ✓ Connected
$ echo "Use diakonos-browser browser_navigate to go to https://example.org. Reply OK." \
    | claude --print --allowedTools "mcp__diakonos-browser__browser_navigate"
OK                                                    # ← Claude as agent called the tool
$ docker exec cuabot-xpra curl -s localhost:9222/json | jq '.[0].url'
"https://example.org/"                                # ← Chromium navigated as a result
```

The agent invocation runs in the same login-zsh / `$HOME` / claude
configuration the pane uses. Confirmed bundle path
`/Applications/Diakonos.app/Contents/Resources/mcp_browser.py` is what
claude reads — no DerivedData hardcoding.

### v1.3 Browser sizing bug — FIXED

**The bug:** X display 2560×1440, Chromium spawned at default 1280×720,
screenshot at 25% fill.

**The fix:** Python CDP helper `resize` action now does three operations:
xrandr mode switch → `Browser.setWindowBounds` via CDP → `wmctrl -r`
reposition. Mode picker selects smallest mode that fits (modes available:
`754x394@50`, `2560x1440@50`, `8192x4096`). `BrowserPaneView` observes
its size via `GeometryReader` and triggers resize with 200 ms debounce.

**Real verification (this session):**
```
# Diakonos at default 1440x900, Browser pane ~705x400:
$ docker exec cuabot-xpra xrandr | grep "*"
   754x394@50    50.00*       ← automatic on BrowserPane mount

# Then manual large resize:
$ docker exec cuabot-xpra python3 /tmp/diakonos-nav.py resize 2400x1300
HELPER_OK
$ docker exec cuabot-xpra xrandr | grep "*"
   2560x1440@50  50.00*
```
