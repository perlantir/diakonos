## Decisions made / non-blockers

- **Hermes pane runs bash, not hermes.** `hermes` is not installed in cua's Docker image. v1 stand-in: login bash with `HERMES_AGENT=1` and `PS1=hermes $`, themed orange. The pane header shows the Hermes icon + orange accent so it's visually distinguishable. v0.2 should detect a host-installed hermes (via something like `which hermes` from the host) and use it instead, or `docker cp` a hermes binary into the container at sandbox-init time. Adding to the Out-of-Scope list. *(Note: per CLAUDE.md hard prohibition I can't edit `PROJECT_STATE.md`; flagging here for Nick to copy across.)*
- **Browser bypasses sandbox state.** A v1 Browser pane that's grayed out while cua boots was the wrong UX — the WKWebView has no cua dependency. `state(for: .browser)` returns `.running` unconditionally. Pane header dot stays green at all times for the Browser pane.
- **Each pane spawns its own `docker exec`.** Could share one shell over multiplexing, but separate exec sessions are simpler and isolated (one shell hanging doesn't affect the others). Matches v1's "one pane = one process" mental model.
- **Browser default URL:** `https://www.apple.com`. Arbitrary; v0.2's preferences should make this configurable.
- **No URL persistence across launches.** Browser pane starts at the default each launch. v0.2 SwiftData task.

## Issues

- **WKWebView and the Hardened-Runtime entitlements:** the Browser pane loads fine in this environment, but on a freshly-installed Diakonos with stricter sandbox/Internet entitlements, WKWebView's network requests would be gated. v1 has `App Sandbox: OFF` (D3) so this is moot for now.
- **No "reset / restart sandbox" UI yet.** If cuabot crashes, all four panes go dark until the user quits and relaunches Diakonos. v0.2 design surface (the "Reset" button in the design's sandbox status popover, screen 06) will address this.
- **Three persistent docker-exec PTYs** are a real resource cost. Empirically: 116 MB RSS app-side, plus the cua container itself (~1.5 GB allocated). Acceptable for v1 on developer machines.
