## TL;DR

Three v1.1 phases landed in one continuous pass:

- **Phase C** — BR Browser pane is sandboxed Chromium streamed from cuabot's Xpra HTML5 server (Approach A). Verified end-to-end via WebKit TCP connection to `[::1]:10000` and live Chromium processes inside the cua container after a Diakonos-driven navigate call.

## What you see at the end (best case)

A 2×2 workspace:

- **Top-left Terminal** — your real `$SHELL` (zsh by default on Sonoma), running in your `$HOME`, with your real `$PATH`. Type `whoami` and see your actual Mac username.
- **Top-right Claude Code** — `claude --dangerously-skip-permissions` running in whatever folder you last picked (defaults to `$HOME` on first launch). The pane header shows the folder's basename in a clickable chip; clicking it pops `NSOpenPanel`. Selecting a new folder kills the running claude and respawns with the new cwd.
- **Bottom-left Terminal 2** — another native shell, fully independent from TL. Drop the v1 Hermes theming and env vars.
- **Bottom-right Browser** — `WKWebView` loaded at `http://localhost:10000/`, which is cuabot's Xpra HTML5 client streaming sandboxed Chromium. URL bar drives Chromium-in-sandbox via `POST /bash`. Back/Forward/Reload via xdotool key injection. Sandbox state surfaces as a dot at the right edge of the URL bar.

Toolbar: workspace dropdown, big spacer, settings button, fullscreen button. **No more sandbox status indicator, no more Manual/Auto toggle.**

Cmd+, opens Preferences with **5 tabs** (General, Panes, Agent, Shortcuts, About) — Sandbox section is gone, Settings no longer crashes.
