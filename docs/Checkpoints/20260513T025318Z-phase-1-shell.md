## Decisions made

- **Toolbar dropdown label:** "Diakonos" (locked from Step 2 default).
- **Pane icons:** SF Symbols colored per kind (`terminal.fill` green, `sparkles` purple for Claude, `bubble.left.and.bubble.right.fill` orange for Hermes, `globe` blue for Browser). The design package's icon spec (screen 09) shows custom hex/cube glyphs, which are real design-asset work — the SF-Symbol mapping is the Phase-1 stopgap matching the spec's "static placeholder" requirement. Phase 4 will revisit if you want true custom glyphs.
- **Pane-header controls:** four icons in the order ellipsis → minimize → expand → close, per the design's right-side control cluster. Minimize/expand/close are wired to no-op closures in Phase 1; Phase 2+ wires real behavior.
- **Split-divider thickness:** 6pt hit area with 1pt visible hairline, accent-soft hover tint, accent-primary active band. Matches the divider state shown in screen 01's component states.
- **Workspace min-pane sizes:** width ≥ 220pt, height ≥ 160pt. Below this the pane content stops being readable.
